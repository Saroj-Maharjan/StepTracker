# Step Tracker
Step tracker intregrate Apple Health to show latest steps and weight in animated, interactive swift charts.

Step Tracker also allows you to upload new step or weight data to the Apple Health app.

# Technology Used
* Swift UI
* HealthKit
* Swift Charts
* Swift Algorithms
* DocC
* Git & github
